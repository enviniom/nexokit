# Permissions Specification

## Purpose

Superseded by the IAM Module specification. Permission model behavior, admin permission endpoints, and permission synchronization are now specified under `openspec/specs/iam-module/spec.md` and `openspec/specs/rbac-authorization/spec.md`.

## Requirements

No active standalone permissions-module requirements remain. The legacy `internal/modules/permissions/` directory has been removed; IAM is the sole boundary for permissions.
