# Users Specification

## Purpose

Superseded by the IAM Module specification. User management routes, payloads, status codes, password change, active/inactive status, and tenant-scoped isolation are now specified under `openspec/specs/iam-module/spec.md`.

## Requirements

No active standalone users-module requirements remain. The legacy `internal/modules/users/` directory has been removed; IAM is the sole boundary for users.
