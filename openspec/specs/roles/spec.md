# Roles Specification

## Purpose

Superseded by the IAM Module specification. Role CRUD, role-permission catalog/assignment, system role protection, reserved slug validation, and role seeding behavior are now specified under `openspec/specs/iam-module/spec.md`.

## Requirements

No active standalone roles-module requirements remain. The legacy `internal/modules/roles/` directory has been removed; IAM is the sole boundary for roles.
